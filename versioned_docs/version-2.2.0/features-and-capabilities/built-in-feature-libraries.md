# Built-in Feature Libraries

**Panacea** is delivered as a ready-to-use, fully integrated feature library, including:

- Pre-integrated core automation capabilities
- Comprehensive documentation
- Ongoing support

![Platform Overview diagram](/img/panacea_runtime.png)

## Library Structure

The `panacea_runtime` folder contains modular libraries supporting multiple test layers:

- **[APITestLibrary](/docs/keyword-reference/api-library/http-session-management)** – API testing keywords and utilities
- **[BrowserTestLibrary](/docs/keyword-reference/browser-library/device)** – Web application testing keywords
- **[MobAppTestLibrary](/docs/keyword-reference/mobile-library/application-management)** – Mobile application testing keywords
- **[CommonUtilsTestLibrary](/docs/keyword-reference/common-utilities/gmail-utils)** – Shared utility and helper functions
