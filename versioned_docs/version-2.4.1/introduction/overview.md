# Overview

**Panacea** Test is a multi-layer test automation platform that provides a comprehensive solution to the challenges organizations face in automating their testing processes. It has been developed by our in-house technology studio with a dedicated focus on scalable and maintainable test automation.

Built on a robust foundation of best-in-class open-source technologies, Panacea avoids reinventing existing tools and instead focuses on optimizing proven solutions. Recognizing that teams often spend more time maintaining automation frameworks than executing tests, Panacea is thoughtfully designed to be simple, extensible, and maintainable. The platform deliberately avoids proprietary tooling and leverages appropriate open-source technologies to ensure flexibility, transparency, and scalability.

**Panacea** is delivered as a two-part package and is intended for use within a controlled development environment such as Visual Studio Code. It is neither a compiled executable nor a hosted SaaS product, thereby providing users with full visibility and control during setup, configuration, and execution.

## Panacea Package Components

**Panacea Runtime**
Contains automation libraries, reusable keywords, configuration files, and sample test cases. This component is delivered as a Git repository.

**Panacea Test**
A Python-based dependency installed via pip, offering runtime utilities, encryption handlers, and execution helpers. This modular design ensures a secure, auditable, and controlled deployment within QA and development environments.

## Key Highlights

### Unified and Consistent Automation

Provides a standardized automation approach that can be seamlessly applied across all application layers, simplifying automation efforts and accelerating team productivity.

### Gherkin-Style Test Scripting

Supports Gherkin-based test scripting, enabling manual test cases to be directly reused within the automation framework.

**Key benefits include:**
- Elimination of the need to rewrite manual test cases in a different scripting language
- Reduced effort and faster expansion of test coverage

### Efficiency and Flexibility

Designed for extensibility while minimizing framework maintenance overhead, allowing teams to focus on test execution and quality validation.
