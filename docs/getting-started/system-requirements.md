# System Requirements

## General Requirements

- **OS:** Windows 10+, macOS 10.15+
- **Memory:** Minimum 8 GB RAM
- **Disk Space:** Minimum 500 MB
- **Editor:** [Visual Studio Code](https://code.visualstudio.com/download)
- **Python:** [3.12.3](https://www.python.org/downloads/release/python-3123/)
- **Pip:** 24.0 (installed automatically with Python)
- **Node.js:** [24.14.1](https://nodejs.org/en/download)

## Mobile Automation (Additional Requirements)

- **Java** (latest version) — [Download](https://www.oracle.com/java/technologies/downloads/)
- **Android Studio** (latest version) — [Download](https://developer.android.com/studio)
- **Appium:** 3.3.0

Install Appium via npm once Node.js is installed:

```bash
npm install -g appium@3.3.0
```

Verify the installation:

```bash
appium -v
```
