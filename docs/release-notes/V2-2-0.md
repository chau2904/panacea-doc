# Panacea v2.2.0 — Release Notes

**Release Date:** April 21, 2026

## What's Changed

### Enhancements

- Added support for Appium 3.3.0
- Test execution is now fully YAML-based, making test runs easier to define and manage
- Introduced a new test orchestrator — run device/browser specific tests, entire suites, or any combination of tags and robot files, automatically distributed and executed across every device or browser defined in your configuration
- XRAY and JIRA integration now fully supports parallel test execution
- Added built-in pre/post suite setup and teardown hooks for mobile and web with automatic Appium and ADB start/stop support and test data capability for storing logs

### Bug Fixes

- Fixed ADB log timestamp normalization for more accurate Log Lens reports
- Fixed scroll into view methods not working correctly on Firefox
- Fixed step-level keyword logs not being updated in OpenSearch when `OPENSEARCH` was enabled
